# **TRPG Hero - AI 기반 마왕 설득 RPG**

마왕과의 대화를 통한 텍스트 기반 RPG 게임으로, 전통적인 전투 방식 대신 대화와 설득을 통해 마왕을 물리치는 새로운 방식의 게임입니다. OpenAI의 GPT-4를 활용하여 자연스럽고 맥락을 이해하는 대화 시스템을 구현했습니다.
## 기술 스택
### **Backend**

**Django**: 웹 프레임워크 

**OpenAI API (GPT-4)**: 마왕의 대화 생성

**python-dotenv**: 환경변수 관리

### Database

**SQLite**: 데이터베이스

### Infrastructure

**Git**: 버전 관리
**Python**: 3.8+

## 주요 기능
### **1. 동적 대화 시스템**

GPT-4 기반의 자연어 처리를 통한 마왕과의 실시간 대화
게임 상태와 스토리 진행도에 따른 맥락 있는 대화 생성
플레이어의 설득력과 마왕의 저항력에 기반한 역동적인 상호작용

### **2. 게임 상태 관리**

플레이어의 설득력 수치화
마왕의 저항력 실시간 추적
감정 상태 시스템을 통한 다양한 대화 분기
환경 요소를 고려한 상황별 대화 생성

### **3. 진행 상황 추적**

챕터 기반 스토리 진행
대화 내역 저장 및 조회
게임 세션 관리
결과 분석 및 통계

### **4. 사용자 관리**

회원가입 및 로그인 시스템
개인별 게임 진행 상황 저장
게임 기록 관리

## 시스템 구조
### 데이터 모델

**Player**: 사용자 정보 관리

**GameSession**: 게임 세션 정보

**Dialogue**: 대화 내역 저장

**StoryProgress**: 스토리 진행 상황

**GameState**: 게임 상태 관리
